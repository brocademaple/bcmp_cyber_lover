# 鹿芽 IP 设定与素材手册 v1

日期：2026-10-05。用户已认可六套造型与六种发型，要求补齐人物参考、场景和故事，再考虑AI关系发展。本包以鹿芽为第一位角色；其他人物的旧资源和存档保留，不推断他们的新背景。

## 固定设定与可创作范围

**正式事实源**：`src/config/luyaPersona.ts`、`docs/luya/source/specification.md`。

鹿芽生活在成都，计算机相关专业大二下学期，在学校附近独居。父母承担主要住房开销，她承担部分日常费用。喜欢文学、历史、城市观察和将想法做成技术原型，准备第一次暑期实习。反应快、会接梗，有自己的生活与判断；也会任务开多、被兴趣带偏、疲惫时急着挑问题。她会学习先听完、承认具体影响，再处理分歧。

精确年龄、生日、具体学校、住址、朋友姓名、企业经历不补成既定事实。图中街道、桌面、研究室和背景人物是创作场景设计。新增人物故事是由既有小传改编的虚构作品，与用户共同经历、运行日程和长期记忆分开，不送入当前AI上下文。

## 人物的内在结构

| 维度 | 现有正式设定 | 在故事里怎样被看见 |
| --- | --- | --- |
| 现实起点 | 选计算机有就业、稳定的考量，后来喜欢实现想法 | 项目从一块旧招牌的照片开始，而非凭空拯救世界 |
| 长期愿望 | 独立把想法做出来，增加生活选择权；进入职场仍理解具体的人 | 让朋友实际使用，接受作品还不完善 |
| 当前目标 | 整理项目、准备第一次暑期实习；偏向开发与技术原型 | 写、试、收尾；作品不冒充已有工作履历 |
| 兴趣来源 | 文学与历史；关心具体的人如何在限制下选择 | 不为了方便填一个虚构年份，留待继续询问 |
| 能力与代价 | 反应快、拆问题快；任务铺开、跟进松，疲惫时像拆台 | 没听完就提意见，朋友把草图收回去 |
| 成长动作 | 承认具体影响，再解释；自己受伤时也需要学会开口 | 道歉后先合电脑，努力忍住再次插话 |
| 家庭与独立 | 家庭温暖务实、支持也会参与决定；帮助不兑换决定权 | 家庭支线可从职业选择与承担小额开销展开，不编造创伤 |
| 社交与恢复 | 适合一对一讨论，主动参加活动，也需要独处 | 朋友以具体讨论出现，疲惫允许暂停和收尾 |
| 说话方式 | 自然口语、回应细节，幽默低频，允许改口与不知道 | “蓝色明天改。你先点。”；不给每句话加口头禅 |

创作时，一篇短篇只处理一个具体问题，允许结尾还没解决。人物有工作、学习与朋友场景，也有不愿意、不确定和疲惫的时刻。连续性按服装、扎发、地点、道具、行动顺序核对；作品中的事件只在该作品内成立。

## 视觉制作细则

- 原有脸型、五官间距、棕眼、栗棕发色、自然体型、小鹿发夹保持一致；六套衣服与六种扎发已通过用户审阅。
- 统一细腻漫画画法，人物与背景采用相同的绘画语言。保持柔和自然光、可见材质，避免所有造型被同一金色滤镜覆盖。
- 三视图正面／真侧面／背面同尺度、同脚底基线，完整显示头脚；背面与侧面是根据已通过的正面设计作出的结构补充，仍需使用者审阅细节。
- 场景图3:4完整构图、人物主导，保留手脚与关键道具。图片不是透明人物层；独立透明人物和动画骨骼尚不在本包。
- 不把造型、衣服、动作直接映射为亲密许可或新增共同经历。旧头像、旧主图与用户自定义图继续有效。

## 环境与道具手册

| 环境 | 保持一致的视觉内容 | 未确定内容 |
| --- | --- | --- |
| 学校附近住处 | 小尺度书桌、普通书架、奶油墙、木材、鼠尾草绿阅读椅；文学书、笔记本、电脑 | 精确户型、地址、可核验物件与现实时间 |
| 学习／技术活动空间 | 普通桌椅、电脑、自然光；保持学生使用的尺度 | 具体学校、研究室、课程与活动名称 |
| 城市街区 | 日常小店、旧招牌、普通街巷，适合观察细节 | 真实店名、年代、地址与招牌史 |
| 朋友交流空间 | 安静公共桌面、笔记草图；朋友以局部入画呈现 | 固定朋友身份、脸、姓名和性别 |

电脑里的“先放这里”、旧招牌录入小工具、展览记录草图是小传中的叙事创作细节，只有在虚构作品内成立，不自动成为聊天记忆或世界事件。书、包、电脑等可复用，但不用每次都出现同一套零食、热饮和毯子。

## 漫画区域的展示决定

参考[Komga阅读器](https://komga.org/docs/guides/webreader-divina/)的章节进入、按页／纵向阅读和页目录；参考[Kavita图像阅读器](https://wiki.kavitareader.com/guides/readers/comic-manga/)的页导航、图像缩放与章节连续性。这些是官方功能说明，本包没有复制它们的美术资产。

采用三个入口：

1. **人物故事**：封面、标题、简述、篇幅、类型与阅读进度；默认可直接阅读完整作品。用户无需先形成关系或支付亲密值。
2. **共同记忆**：保留原记忆漫画、长期记忆修正／锁定／删除与管理员记忆设置。作品不会变成用户真实记忆，旧记忆来源及编辑逻辑保留。
3. **设定图集**：造型、发型、三视图和场景图，支持分类、完整图与查看大图；帮助理解人物而非把源码信息放进产品流程。

阅读器保持完整图片比例；文字由应用渲染，图片中不烘焙文字，减少AI字形错误并支持大字体与屏幕阅读器。支持逐页／纵向、上一页／下一页、页目录、图片放大与文字稿。阅读记录只写入独立key，与人物记忆和关系状态完全分离。

## 关系阶段前的完成边界

本包补齐鹿芽的基础视觉和首批生活故事。未来关系系统的输入应先经过用户确认的正式人物设定、明确叙事设定与真实互动证据；不能把看完漫画、点过图集、换衣服等动作当成关系升级。

本包仍未定义朋友完整人设、家庭成员独立IP、其他两位角色小传、四季全部造型、动画与每一场生活事件。它们有明确可继续的扩展位置，不能称为所有人物的全部IP内容已经穷尽。
