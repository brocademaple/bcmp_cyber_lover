# 首批人物故事分镜脚本

2026-10-05。源稿：`docs/luya/stories/01-persona-sketch-draft.md`。三篇均为虚构人物故事改编，没有用户角色，不推进聊天、关系、日程、实习或记忆。图像不写中文字，旁白与对白保留在应用中，可完整阅读与编辑。

## S01《年份不详》· 漫画 · 2页

主题：她喜欢把想法做出来，也愿意承认不知道。

第1页，三格：
1. 她想给拍过的旧招牌做一个小小的存放处。照片、地点、日期，再加几句当时的记录。
2. 录入页面有一个必填项：年份。拿自己的照片一试，卡住了。
3. 她知道拍摄日期，却不知道那家店什么时候开的。备忘录里只有一句：“下次问问老板。”

第2页，三格：
1. 随便填一个，也能进去。她盯着空格，最后删掉了必填限制。
2. 她加了一个选项：“年份不详。”照片存进去了，页面比刚才顺眼。
3. 第二天，她带着照片又去那条街。店门关着，下午还有课。“下次问问老板”暂时留着。

造型连续性：家中L02低马尾；最后街头格L03高马尾。不要画出已完成老板采访或已知开店年份。

## S02《蓝色明天改》· 漫画 · 2页

主题：动手完成和愿意改进的快乐，不要求作品初次就完美。

第1页，三格：
1. 她写的小工具终于跑起来。功能很少，界面也不好看。
2. 她来回点了几遍，关闭，再打开。东西还在。
3. 她给朋友发了一张截图。

第2页，三格：
1. 朋友说：“这个蓝色有点丑。”
2. 鹿芽：“蓝色明天改。你先点。”朋友点完，说能用。
3. 她高兴了一阵，又把那个蓝色改了。

造型连续性：L02低马尾，同一书桌。朋友只通过文本出现；屏幕用抽象图形，不引入真实公司或项目履历。

## S03《先合上电脑》· 绘本短篇 · 2页

主题：聪明和直接也会伤人，修复需要具体行动。

第1页，整页插画：
朋友给她看展览记录页面的草图。她正在改项目，听了几句便指出一个问题，接着又指出一个。朋友把图收回去：“我还没讲完。”过了一阵，她想起那张图上有一小块字，自己根本没读到。

第2页，整页插画：
她发消息：“刚才我有点急，你还没讲完，我就开始挑问题了。”解释自己的话打了又删。“你还愿意讲的话，明天我听。”第二天，她先合上了电脑。听到一半仍想插话，手指敲了一下，又停了。这回，她把那一小块字也看到了。

造型连续性：L04半扎发，同一匿名公共学习空间。朋友只画手和局部肩背，不补固定姓名、性别或脸。没有恋爱升级或用户被代入。
