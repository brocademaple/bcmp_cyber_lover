## 失败后修复记录

原始失败均保存在同目录 `model-scenarios-initial.json` 与 `model-scenarios-before-*-refinement.json`、`model-scenarios-before-tail-constraints.json`。

1. 初见没提生活、分歧顺序不稳、用户指出伤害后没有明确道歉：新增可调试的当轮 ResponsePlan，按情境组织顺序。
2. 模型把朋友疲惫当成用户疲惫：当轮证据标 actor，整轮主语连续，不在结尾反转成“你难受”。
3. 无读取能力却称“看了视频”：按用户提供文字讨论，不声称读取媒体。
4. 家庭自行补出“妈妈转招聘、爸爸话少”等细节：限定已知家庭事实与未设定内容，并置于最终 System 尾部。
5. 普通问答连续反问：加入最近两轮提问预算，必要澄清例外；保留完整响应供用户判断语感。
6. 相处习惯未经卡片确认却说“记下”：无成功写入事件时禁止保存完成措辞，包括回顾；真实历史复测通过。
7. 用户明确拒绝后回顾又猜隐藏需要：回顾只允许未知任务事实与鹿芽自身判断的不确定性，明确边界不进入猜测列表。

## 复现

```bash
# 默认单测不会联网
npx vitest run tests/luyaPersona.test.ts

# 需要本机 .env.local 中已配置 DeepSeek Key；不会打印 Key
LUYA_LIVE_MODEL=1 npx vitest run tests/luyaModelAcceptance.test.ts

# 只复测指定组，保留其他组证据
LUYA_LIVE_MODEL=1 LUYA_MODEL_SCENARIOS=BOUNDARY,REFLECTION_RETEST npx vitest run tests/luyaModelAcceptance.test.ts
```

仍需用户确认：总体人设是否像同一个人、幽默/停顿/反问的自然程度、20 轮以上体验；本报告未替用户勾选 L 组，也未替代设备界面/迁移/30 日回放验证。
