# 鹿芽开发交接包 v1.0

建议阅读顺序：

1. `鹿芽_人物设定与活人感机制_开发实现规格_v1.0.md`  
   开发唯一执行规格，包含人物事实、系统边界、数据结构建议、文件改造地图、追踪矩阵、开发验收与 Stop-ship 条件。

2. `鹿芽_用户逐项验收清单_v1.0.md`  
   开发完成后，由用户按顺序逐项确认，共 121 个可勾选项目。

3. `鹿芽_原始导出资料_2026-09-18.md`  
   旧版代码与配置的资料底座，用于定位历史实现和核对数据边界。它不是新版人物设定的最终事实源。

执行原则：

- 新版人物事实以“开发实现规格 v1.0”为准。
- 原始资料中的旧台词、旧 Prompt、预置漫画和分析示例不得自动当作新设定或真实经历。
- 不得只修改一段 Prompt；首页、状态、关系、记忆、通知、房间、推断、迁移和验收必须一起对齐。
- 出现规格中的任何 Stop-ship 条目，不得发布。
