# 鹿芽基础体验整改与验收

日期：2026-10-05。对应原始 [26 项问题清单](basic-experience-audit-2026-10-05.md)。三个 sub-agent 分别负责图片可靠性、首页体验、共同房间；主 agent 负责共享抽屉、提醒保存、整合和浏览器验收。所有操作针对实际 Expo 应用，没有用静态页面替代，也没有启动 iPhone 模拟器。

## 用户确认的范围

- 保留“节奏放缓”的生活说明；明确已有状态入口。手动状态用于本次互动，5 分钟内进入聊天会带入该状态，重开首页按原有生活日程恢复。
- 共同房间采用沉浸场景、布置抽屉、有限摆件预设。墙色作用于右侧墙面色调；灯光作用于局部氛围。自定义名称使用通用摆件。房间商量/所有权规则保持原样。
- 延续鹿芽现有画风、稳定 ID `qingning`、旧图与用户自定义图优先级。生活横图完整显示并用背景延展；房间新增日夜 3:4 图，旧横图保留回退。

## 五类主要问题

| 用户反馈 | 结果 | 实际验证 |
| --- | --- | --- |
| 图片不稳定、横竖比例跳变 | 统一有限重试和本地回退，固定首页画面及操作区域 | 生活/经典切换时聊天按钮 y=646、高50，底部入口 y=756、高53；故障测试首选失败1次后显示本地头像，双来源失败2次停止，手动重试累计4次停止，恢复后成功1次且计数稳定 |
| 首页按钮层级 | 人物底层、柔和悬浮操作区，横屏左右分区 | 390×844、320×568、844×390、1280×900 实际截图；横屏曾遮挡立绘，修正后完整显示 |
| 档案/聊天头像难加载 | 共用头像来源与本地回退，不把失败锁死为鹿图标 | 首页→人物档案→聊天均有实际人物头像截图，使用512人脸图；自定义来源优先逻辑单测通过 |
| 三个入口与状态不明显 | 记忆漫画/人物档案/提醒成为明确按钮，状态采用有标题的抽屉 | 三入口逐项打开；状态选择、反馈、即时进入聊天；提醒改23点、完成返回、重开仍23点；漫画全屏打开与关闭按钮走通 |
| 房间长列表割裂 | 单场景＋四操作入口＋抽屉；可见有限摆件、物品详情、应用/取消、Toast | 日夜实图；预览取消不保存、应用持久化、添加绿植后重进仍可见；公共区灯/绿植点击框不重叠；待商量物品只提供去聊天，带上下文但不自动发送 |
