# 鹿芽形象扩展方案 v1

2026-10-05 · 用户已同意按本方案进入出图。现已完成[六造型与六发型审阅图](appearance-v1/README.md)，具体成图待审阅；未改动人物设定、替换原素材或接入应用。依据现有鹿芽图、`src/config/luyaPersona.ts`和本次美术盘点。

## 形象方向

**有自己生活的年轻大学生：温暖、灵动、自然，偶尔利落，衣橱有可反复搭配的日常单品。**

保留现有精细暖色漫画插画，增加低饱和蓝、绿、牛仔与自然光，使形象从长期固定的米白针织／灰粉搭配，扩展到上课、做项目、城市散步、看展、在家阅读等情境。穿搭体现她的生活和兴趣；每套有明确轮廓与材质变化，避免只换颜色。

官方设定：成都生活、计算机相关专业大二、喜欢文学历史和城市观察、准备第一次暑期实习。精确年龄、学校及身体尺寸未设定，本方案不新增这些事实。以下衣服和造型均为美术候选，不能作为她实际购买、出行或参加活动的记录。

## 固定识别特征

| 保持一致 | 可变化 |
| --- | --- |
| 原有脸型、五官间距、棕色眼睛、自然表情习惯 | 微笑程度、视线、轻微疲惫或专注 |
| 栗棕发色、柔软发质、原有刘海和鬓发特征 | 披发、半扎、低马尾、松丸子、侧辫 |
| 自然体型与头身比例，以现有母版为准 | 服装轮廓、站坐姿势，衣料松紧变化 |
| 单个小鹿发夹作为常用标志 | 发夹位置、小素色发绳；不把鹿图案铺满服装 |
| 同一套细腻漫画面部画法 | 色彩、服装材质、日夜光线 |

不把精确身高、年龄、罩杯、生日等写进图像提示词；不因换装更换脸型、肤色、发色或大幅改变身材。人物“元气”也不要求每张都大笑、正视用户或伸手招呼。

## 素材规格与制作次序

1. **身份母版**：从现有main／headshot提取参考，确认正面和3/4面部、全身比例、发色、发夹。侧面或背面参考属于新设计，需核对一致性。
2. **造型提案图**：先输出一张六造型总览和一张六发型对照图，全部标注提案ID。总览用于方向审阅，不能直接拆成运行素材。本批已由内置imagegen参照现有母版制作，图与完整提示词保存于`appearance-v1/`。
3. **独立成品**：确认后逐个输出6张独立完整人物图，优先统一3:4构图；头顶、鞋、手和发夹均完整，四边留余量。设计主图采用中性底，供衣服和比例验收。
4. **页面用途**：若需叠加房间，再单独制作／检查真实Alpha透明人物PNG，不能把中性背景版当透明人物使用。全身3:4与聊天半身4:5、512²头像是不同裁切用途，须分别构图或人工检查，不靠盲目自动裁切。
5. **生活场景**：首批另选校园做事、居家阅读、城市观察三张，统一3:4人物构图与已选造型。保持人物和环境的漫画语言；旧横图保留回退。此步骤涉及后续页面适配，本轮不实施。

服装、发型、表情、动作、背景、光照分别登记。它们是制作维度；当前图片都是完整绘制成品，尚无可直接自由拼装的换装系统。衣服不绑定亲密等级，造型切换也不写入共同经历。

## 逐张验收

- 去掉背景和衣服提示，仅对照脸部仍可识别为同一鹿芽；眼形、鼻嘴距离、发色及体型稳定。
- 衣服从轮廓、层次或材质上有区别，不只更换颜色；一套单品结构前后合理。
- 发型扎点和长度可读，发夹、耳朵、发际线与辫子无穿插错误。
- 全身及半身规格各自完整；头像裁切看得到人物表情，缩到64px仍可辨认。
- 手指、肢体、包带、领口、袖口和鞋成对关系正常。
- 透明图实际Alpha可读，无假棋盘底、残留场景或破碎轮廓；全身图不通过半透明设置伪装抠图。
- 站姿、表情不都相同；情绪和衣服解耦，动作图不被误标为情绪事实。
- 归档参考图、提示词、尺寸、SHA、造型ID及用途；新图独立版本化，保留旧资源、稳定角色ID和用户自定义图片。
- 若后续接入页面，另跑项目规定的类型／视觉／存储回归并提供当前bundle实际截图，本轮规划不代表应用展示已更新。
