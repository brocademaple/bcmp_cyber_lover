# 鹿芽基础体验问题清单

日期：2026-10-05。状态：原始审查记录；本轮整改结果与验证边界见 [验收记录](basic-experience-acceptance-2026-10-05.md)。

依据：用户本次 iPhone 真机反馈，以及当前工作区首页、角色档案、聊天、记忆漫画、提醒、理解记录、共同房间的源码。另参考既有 `docs/luya/art-v1/room-mobile.png` 理解页面结构；该截图是历史 Web 预览，不能证明当前 iPhone 的实际渲染。

本轮只整理问题与解决方式，没有修改运行代码或用户数据。图片首次加载失败的具体设备原因，仍需结合真机重现和加载错误记录确认；下文的容错缺陷已能从源码确认。

## 关键假设与整体方向

- 用户所说“鹿牙”按当前角色“鹿芽”理解；“生物画面”按首页的“生活画面”理解。
- 首要体验设备是用户自己的 iPhone，竖屏优先；保留横屏适配，不要求用户改用模拟器。
- 保留现有角色画风、经典立绘、生活插画和关系规则。恋爱陪伴氛围通过画面、留白、灯光与组件体现，不提前改变关系阶段。
- 首页采用人物/场景作为底层，身份与状态放在顶部，聊天和常用入口悬浮在下方。文字和按钮使用局部柔和遮罩，避免整幅立绘被蒙白。
- 同一页面的画面容器比例保持稳定。首轮建议以竖向 3:4 为设计基准，结合真机可用高度调整；横图需要竖向适配构图，不能直接拉伸或强行裁掉主体。
- 房间采用竖向场景主页面，布置和物品管理通过底部抽屉完成。Toast 用于“已保存”等短反馈；选择、预览、确认以及失败后的重试都放在抽屉中。

优先级：P0＝阻断基本图片体验；P1＝本轮体验整改主体；P2＝随后补齐的一致性、可读性与效率问题。它们代表处理顺序，不代表已经修复。
