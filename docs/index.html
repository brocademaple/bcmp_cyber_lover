product decision shipped

首页已经从角色轮播，改成陪伴空间。

角色不再只是左右切换的卡片，而是一个“正在生活着”的存在。首页只回答三件事： 她是谁、她现在是什么状态、你可以怎样自然地进入聊天。

01

一个情绪中心

用完整角色视觉和今日状态建立关系感，减少多入口干扰。

02

少一点功能展示

把服务配置收进更轻的设置层，首页只保留角色状态和关系入口。

03

多一点被惦记

通知、开场白、记忆摘要都围绕“她会回来找你”来组织。

core flow

主路径只保留三步

Step 1

选一个会在意你的人

先确认角色气质，再进入服务配置。上手不再像填后台表单。

Step 2

在陪伴空间里打开聊天

首页承载角色状态和每日入口，聊天是关系自然延伸。

Step 3

让记忆沉淀成关系

档案、纪念日、日记都服务于“她越来越了解你”。

character asset library

角色不止一张立绘，而是一组会呼吸的状态。

v2 资产库为每位角色准备主视觉、头像、情绪、动作和记忆场景。首页等待时会轻轻切换状态， 让她们看起来像正在陪你度过一段时间。

relationship memory

记忆不是功能，是关系的证据。

新版把“记忆库”和“角色日记”从配置感里拿出来，用更像关系档案的方式呈现： 今天聊了什么、她记住了什么、你们之间发生过什么。

鹿芽 她记得你晚饭随便糊弄。
纪遥 她把沉默也算作回答。
凛夜 她嘴上嫌你麻烦，手里已经暂停游戏。
