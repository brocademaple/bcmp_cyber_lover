how it works

聊天、记忆、封瓶

鹿芽陪你慢慢说完一件事。记忆留在本地，你可以修改、锁定或删除。说完之后，茶馆里的封瓶仪式是一个出口，让你重新回到现实生活。

01

聊天

鹿芽倾听，不评判。慢慢说，不着急。

02

记忆

每段对话的记忆留在本地，你随时可以修改或删除。

local trust

对话和记忆都在本地

所有聊天记录、记忆数据和角色状态都保存在你的设备上。你可以随时查看、修改、锁定或删除任何一条记忆。API Key 加密保存，不会上传到任何服务器。
