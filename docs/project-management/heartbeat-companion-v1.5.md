# 心动伴侣 V1.5｜版本目标、交付进度与支持清单

> 项目方向：先把“可信伴侣”和“角色创作”做成闭环，再逐步进入 Live2D / 3D 动态形象。本文是飞书项目文档的本地源稿；个人飞书用户授权恢复后可直接同步。

## 一句话愿景

让用户能创作一个有稳定人设、会记住共同经历、关系能够持续成长，并且所有关系数据都可掌控、可恢复的长期数字伴侣。

## 版本路线

| 版本 | 核心目标 | 用户可感知结果 | 完成标准 |
|---|---|---|---|
| V1.1 可靠底座 | 连接、错误、数据恢复 | 配置错误在进入聊天前被发现；失败可诊断；聊天和角色可备份恢复 | API 连接前置验证；诊断中心；本地备份与恢复前快照；历史兼容检查通过 |
| V1.2 可信记忆 | 记忆来源和控制权 | 用户知道角色记住了什么，能修正、锁定或删除 | 记忆关联来源消息；去重；可信度；记忆库管理；旧记忆兼容 |
| V1.3 关系成长 | 关系阶段与共同时间线 | 关系由真实互动推进，能回看经过确认的共同经历 | 四阶段关系模型；阶段里程碑；纪念日/记忆时间线；日记不编造经历 |
| V1.5 角色创作工作台 | 简单创作、专家编辑、质量检查、版本回退 | 无需写 Prompt 也能创建角色；高级用户可以精调；误改可恢复 | 自定义角色；简单/专家模式；本地角色体检；角色定义版本；关系数据与人设版本隔离 |
| V1.6 动态形象探索 | Live2D 优先，3D 后置 | 角色在待机、说话和情绪变化时具备连续动态反馈 | 先完成渲染技术验证、资源成本模型和降级策略；不阻塞伴侣与创作主线 |

## V1.5 本轮交付状态

### 已完成

- 新增“角色创作工作台”，支持自定义角色、简单模式和专家模式。
- 简单模式根据背景、性格、目标、口头禅和边界生成结构化角色规则，全程可离线运行。
- 新增角色体检：检查身份、语气、行为、边界、记忆触发和开场白完整度。
- 新增角色版本记录和回退；回退只改人设定义，保留聊天、记忆、日记和关系状态。
- 长期记忆新增来源消息、可信度和状态；支持修正、锁定、删除与内容去重。
- 新增关系四阶段与已确认事件时间线。
- 新增本地数据备份、恢复前自动快照和最近错误诊断；API Key 不进入导出文件。
- Onboarding 在保存配置前真实测试文字模型连接，API Key 默认隐藏。
- 移除通话页固定文案伪装语音识别的行为；未接入语音转写时明确说明配置缺口。
- 本地日记基于实际消息生成，不再推断不存在的情绪或关系进展。
- 修复聊天恢复来源优先级，旧快照不再覆盖 SQLite 当前消息状态。
- SQLite 改为增量 upsert；消息队列持久化并支持异常退出恢复。
- API 请求增加超时和取消；图片进入稳定媒体目录并随备份迁移。
- 备份升级为带完整性校验和中断回滚的 schema v2，继续兼容 schema v1。
- 新增文件导入/分享、ESLint、Vitest、GitHub Actions 和可复现锁文件。
- 移除首屏大字体阻塞，Web 应用包从约 141 MB 降至约 68 MB。

## 数据安全边界

- 不清空 AsyncStorage、SQLite 或应用文档目录。
- 聊天继续兼容主索引 `@bcmp_chat_db_v1_${characterId}`、旧记录 `@bcmp_messages_${characterId}` 和文件快照。
- 恢复前自动创建 `pre-restore` 备份；导入不会覆盖 API Key。
- 角色人设版本不包含聊天、记忆、日记、纪念日和关系状态，避免一次回退抹掉共同经历。
- V1.5 本轮不启动 Simulator；视觉检查以静态检查和 Web 导出为阶段证据，真机像素验收列为白天发布补充项。
- 普通用户模式不再持久记录原始 Prompt、用户文本和角色回复；完整 Debug Trace 只在 admin 模式收集。

## API 与配置支持清单

| 能力 | 当前状态 | 需要的配置 | 缺失时行为 |
|---|---|---|---|
| 文字对话 | 已接 OpenAI-compatible | Base URL、API Key、文字模型名 | 连接测试失败，不保存错误配置 |
| 图片理解 | 已有调用入口 | 支持多模态图片输入的模型名；提供商需兼容图片消息格式 | 记录为可恢复诊断，不影响本地聊天历史 |
| 语音朗读 | 已接系统 TTS | iOS / Android 系统语音 | 使用本机声音，无额外云 API |
| 语音转写 | 尚未接入 | Speech-to-Text API；建议兼容 Whisper 的音频转写接口 | 明确提示待配置，不伪造转写结果 |
| Live2D | V1.6 技术预研 | Cubism SDK 授权、模型文件、动作/表情参数 | 继续显示现有静态角色素材 |
| 3D | 后置探索 | VRM / GLB 资产、渲染引擎、设备性能预算 | 不影响伴侣与角色创作功能 |

## 白天需要用户处理的事项

1. 重新登录个人飞书 CLI 用户身份；当前 `alex` profile 的用户 token 和 refresh token 已过期。
2. Simulator 可用时，检查首页、聊天、长期记忆库、关系时间线、角色创作工作台、数据恢复六个可见页面。
3. 如需语音输入，选择 Speech-to-Text 提供商以及可接受的音频上传与隐私策略。
4. V1.6 开始前决定 Live2D 首发角色、模型来源和单角色资源预算。

## V1.6 建议范围

V1.6 只做一位角色的 Live2D 垂直切片：待机呼吸、眨眼、说话口型、四种情绪和静态降级。先量化包体、内存、模型制作工时与授权，再决定是否扩到三位内置角色。3D 作为独立预研，不与 V1.6 承诺绑定。
